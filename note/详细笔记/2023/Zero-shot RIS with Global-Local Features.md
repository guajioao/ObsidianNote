# Zero-shot Referring Image Segmentation with Global-Local Context Features
CVPR2023
# 摘要
Referring image segmentation (RIS)的目的是找到与给定句子所描述区域相符合的分割掩膜。为了克服数据集昂贵问题，作者提出zero-shot的RIS方法，即利用CLIP的交叉模态知识。
* 提出掩码引导的视觉编码器，来获取图像的全局和局部上下文信息
* 使用现成的掩膜生成技术，获得细粒度且详细的，实例级的groundings（掩膜？）
* 引入全局局部文本编码器，分别地获得整个句子和目标名词短语的特征
* 实验结果：本文方法优于一些zero-shot基线，甚至优于弱监督RIS方法

## 总体流程：
结构图:![[用全局局部特征做RIS_结构图.png]]
1. Global-Local **Visual** Features
	1. Mask Generator 生成掩膜
	2. 生成Global Feature
		* 用整图生成图像特征
		* 用生成的掩膜与整体特征重叠
		* 生成被遮住的图像特征
		*  生成全局特征
	3. 生成Local Feature
		* 用生成的掩膜采样出对应的图片
		* 用CLIP的Image Encoder生成Local feature
	4. 生成的Local与Global 特征相加获得Global-Local **Visual** Features
2. Global-Local **Textual** Features
	1. 整个文本通过CLIP文本编码器，生成Global textual feature
	2. 用目标名词短语提取器提取出目标名词短语
	3. 将目标名词短语提取器通过CLIP文本编码器，生成Local textual feature
	4. 生成的Local与Global 特征相加获得Global-Local **Textual** Features
3. Global-Local **Visual** Features与Global-Local **Textual** Features计算相似度，根据相似度选择出与句子最相关的掩码

## 一、引言 Introduction
* CLIP在目标检测、语义分割、图像说明、视觉问答的任务都有出色的zero-shot迁移能力，但并不能直接用于解决如目标检测和图像分割这样的密集问题。
	* 像素级密集预测任务依然困难，因为**图像级**对比预训练任务与语义分割这样的**像素级**下游任务之间依然有巨大的**gap**
	* 已经有几个尝试来缩短这一差距，但是这些工作目标是**微调模型**，仍需要特定任务的注释，依然非常昂贵。
* RIS任务，比较困难，且为其收集数据集也很困难
	* 已有人提出了一种弱监督方法来克服数据集问题，但是仍需要与目标数据集图像匹配的高水平文本注释
	* 本文研究如何从CLIP的预训练知识中零样本迁移到RIS任务
* RIS还需要全面地理解语言和图片，并需要密集的实例级预测（需要预测多个实例）
	* zero-shot迁移到图像分割已经有一些研究，但是不能直接迁移到RIS任务来，因为两个任务之间具有不同的特性
	* 语义分割不需要区分实例，而RIS需要区别实例级的掩码
	* 此外，在同一个类的多个实例中，只能选择该表达式所描述的特定实例
	* 如图像中，需要检测出三个实例：绿(猫)、蓝(电瓶车)、红(猫),在综合考虑local和global语义之后选择符合句子语义的绿猫而不是在下方的红猫。![[Pasted image 20231004170338.png]]
* 在论文中提出一个零样本的RIS基线
	* 使用CLIP的预训练模型
	* 全局和局部的图像语义和表达式处理方式一致
	* 提出掩码引导的视觉编码器，来获取图像的全局和局部上下文信息
	* 提出全局-局部文本编码器，通过目标名词捕获局部上下文
	* 通过结合两个不同的上下文层次，此方法能够理解全面的知识，同时又能理解目标物体的特定特征
	* 该方法不需对CLIP进行额外训练，依然优于所有基线和弱监督RIS方法
* 工作总结：比其他基线方法结果更好，也优于弱监督RIS方法

## 三、方法 Method
### 3.1整体框架
* 因为需要在嵌入空间中学习图像和文本特征，因此采用CLIP来利用图像和自然语言预训练的跨模态特征
* 由两部分组成：
	* 提取视觉特征的global-local 视觉编码器
	* 提取文本特征的global-local 自然语言编码器
	* 视觉编码器
		* 使用无监督掩码生成器生成掩码proposals
		* 为每一个proposal在全局和局部分别提取两个视觉特征，然后组合二者
		* 全局特征可以全面的表示masked区域和其周围的区域，局部特征捕获特定的掩码区域特征。这在RIS任务中非常重要，因为需要用目标的综合全面的表达来聚焦于一个小的特定目标区域
	* 文本编码器
		* 由CLIP文本编码器提取特征
		* 使用**spaCy**提取一个关键名词性词组，并将它的特征与全局的句子特征结合
	* 视觉编码器和文本编码器以一致的方式处理全局上下文和局部上下文信息
* 本文的目标函数：
	* 给定输入为图像I和表达式T，目标为找到文本和视觉特征余弦**相似度最大的掩膜** ![[Pasted image 20231004193759.png]]

## 五、实验结果
* 数据集：在RefCOCO,RefCOCO+和RefCOCOg数据集上评估
	* RefCOCO,RefCOCO+和RefCOCOg分别有19,994、19,992和26,711张图像，分别有142,210、141,564和104,560个参考表达式。
	* RefCOCO和RefCOCO+的表达式较短，一个表达式平均包含1.6个名词和3.6个单词，而RefCOCOg表达的与较长句子的关系更复杂，平均约有2.8个名词和8.4个单词
* 评价指标：使用联合的整体交叉（oIoU）和联合的平均交叉点（mIoU），这是参考图像分割任务的常见指标。
* oIoU是用交集的总面积除以并集的总面积来衡量的，其中的总面积是通过累积所有的例子来计算的。

#### 5.3 结果总结
* 主要结果。
	* 为了进行公平的比较，包括基线在内的所有方法都使用FreeSOLO掩码提案来生成最终的输出掩码。
	* 虽然**与完全监督的参考图像分割方法相比仍存在差距**，但与具有相同上界的基线相比，我们的方法显著提高了性能
* 对**不可视领域Unseen Domain**（？）的零样本评估
	* 我们的方法优于SoTA的监督方法和弱监督方法，尽管我们的模型从未在RIS监督下进行过训练。
	* 当在RefCOCO数据集（unseen column）中看不到的类的子集上进行评估时，监督方法显示出显著的性能下降，而我们的方法在这个子集上工作非常稳定。
* 与few-shot下的监督方法比较
	* 监督方法的few-shot依然打不过本方法的zero-shot（作者没做本方法的few-shot）
* 消融实验
	* Mask质量的影响：将其他baseline使用真实GT的掩膜，本方法依然不变，结论是依然表现得比其他好
	* 全局-局部上下文特征的影响：分别用全局、局部和全局-局部进行训练，结论是是Global-Local特征效果最好
	* 定性分析：
		* 只使用局部特征可能会找错实例
		* 只使用全局特征更多关注上下文信息，但可能找错对象类别
		* 结合二者成功找到正确对象类的正确实例

## 六、结论
* 提出简单而有效的RIS分割框架，主要通过CLIP的图像文本跨模态来迁移知识
* 提出全局局部上下文编码来计算图像与表达式之间的相似性，
	* 目标对象的语义，和与其他对象之间的关系，都在一个统一的框架中处理（指的是都使用全局-局部特征来处理？）
* 该方法显著优于所有的基线方法和弱监督方法。
