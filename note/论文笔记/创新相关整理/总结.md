# 不需要训练模型的方法
##### Diffusion Model is Secretly a Training-free Open Vocabulary Semantic Segmenter
* 特点：无监督，无训练
* 方法总结
	* 结构图
		* ![[Pasted image 20240115160951.png]]
	* 图像通过正常加噪过程变为$z_t$，通过BLIP获得图像的Caption并通过文本编码器提取为文本特征
	* 图像与文本"bus++ parked"做cross attention，融合每一层的交叉注意力结果
		* ![[Pasted image 20240115162256.png]]
		* 不同层的注意力信息关注点不同、噪声程度不同，融合全部交叉注意力图能更好的得到完整正确的注意力图
	* 图像与自己做self-attention，只融合最大分辨率的两个自注意力图
		* 交叉注意力层能够定位，但缺乏清晰的边界，内部也可能出现空洞
		* 只用了最大的两个自注意力图，原因作者没有详细讲，但从结果来看是要更好的
		* ![[Pasted image 20240115163256.png]]
	* 用组注意力图补全交叉注意力图，获得语义Mask
		* ![[Pasted image 20240115162607.png]]
		* 
* 创新之处
	* 用（图像与文本的）交叉注意力图定位目标物体；用自注意力图补全前者缺失的边界和内部空洞
* 可借鉴的点
	* 定位目标物体的方式(cross attention)与(self-atention)补全内部和边缘的手段
	* 缺陷：只有注意力图的情况下难以避免的会出现误关注其他信息的情况，比如“train”关注了站牌和轨道

##### Diffusion Models for Zero-Shot Open-Vocabulary Segmentation
* 特点：开放词汇表，DM生成相同类别图像后聚类，无需训练
* 方法总结
	* 认为具有相似captions的图像视觉上常常是不同的，因此不能直接将图像与文本进行比较
	* 结构图
		* ![[Pasted image 20240112085209.png]]
	* 分为两个阶段：
	* prototype sampling原型采样阶段
		* 特征提取器使用SD+DINO+CLIP
		* 以"cat"和"dog"为query举例。先使用扩散模型分别生成一组猫的图片，一组狗的图片，再分别用特征提取器和segmenter进行处理，得到instance-level prototypes实例级原型，再通过实例原型平均加权的方法获得class-level原型
			* segmenter：无监督实例分割方法，比如CutLER，产生多个二值掩码。选择average attribution最高的作为前景；最低的作为背景
		* 通过Prototype aggregation原型聚集（K-Means聚类方法），形成正负原型，正原型即类别；负原型即背景。从猫狗的图像中提取的特征将聚集为猫原型、猫背景原型、狗原型和狗背景原型
	* 分割阶段
		* 输入的图像将被提取为特征然后与原型比较，得到推理mask
		* CLIP过滤器基于整张图像的内容过滤掉不相关的原型
* 创新之处
	* 从大量DM生成的图像提取类别原型和背景原型，输入图像的特征与这些原型进行比较
* 可借鉴的点
	* 若使用无监督分割方法，可以采用类似的与聚类中心对比相似度的思想【SwAV？】

##### Dataset diffusion_ Diffusion-based synthetic dataset generation for pixel-level semantic segmentation
* 特点：生成图像同时生成对应的分割map
* 方法总结
	* 结构图
		* ![[Pasted image 20240115213938.png]]
	* 对于给定的类别，使用LLM生成或者直接使用VOC/COCO的Captions
	* 用SD生成符合描述的图像，同时利用在这个过程中产生的自注意力图和交叉注意力图生成精细的交叉注意力图作为伪标签
	* 交叉注意力使用的文本特征只有label特征不是整句的特征
	* 生成的图像用于自监督语义分割训练，语义分割器生成的mask与伪标签计算损失【+0.7%】
	* Uncertainty-aware cross-entropy loss设计了一个$(\alpha,\beta)$的阈值，预测值在这个区间内表示预测的是不确定的mask。最终计算损失的时候忽略这些来自不确定区域的损失【提高1%】
* 创新之处
	* 结合多个labels生成Caption，让SD生成复杂图片
	* 使用注意力生成掩码
	* 避开不确定区域计算损失
* 可借鉴的点
	* 避开不确定区域计算损失这个设计与ZegCLIP使用的NEL非互斥损失是否有相似的作用？避免不确定的区域损失回传或许
	* 生成图像时利用其注意力图生成掩码
