## 不需要生成数据+训练模型的方法

ARXIV_Towards Training-free Open-world Segmentation via Image Prompt Foundation Models
输入提示图像和待分割图像，分别提取**DINOV2和SD特征**融合，对提示图像特征做**无监督显著性目标检测**提取前景特征提示，然后和输入图像的**特征匹配**，得到前景背景候选点，送给**SAM继续分割**。

ARXIV_Diffusion Model is Secretly a Training-free Open Vocabulary Semantic Segmenter
不需要训练模型的DiffSegmenter，输入图像和类别集合或者一句话给SD，通过去噪UNet网络的**交叉注意力机制得到粗略图**，通过**自注意力机制优化**，设计文本提示和类别过滤机制，输入图像给BLIP生成CAPTION，通过CLIP初步判断类别关键词。对**弱监督语义分割**任务，还要用**CRF优化**得到伪真值，然后训练语义分割模型。

![](file:///C:/Users/呱唧owo/AppData/Local/Temp/msohtmlclip1/01/clip_image004.jpg)

Factorized Diffusion Architectures for Unsupervised Image Generation and Segmentation    

在扩散模型的UNet Encoder之后增加一个**Mask Generator**生成掩码，Decoder分为多个分支，对每个带掩码的**分支做去噪**，最后**去噪结果合并**。问题是如何让Mask生成的？【多通道区分？】

ARXIV_Diffuse, Attend, and Segment_ Unsupervised Zero-Shot Segmentation using Stable Diffusion

输入一张图片实现zero shot分割，主要依赖于图片输入给SD的自注意力，首先对**自注意力图聚集**，然后基于**相似性和KL散度**进行合并，非极大抑制

## 需要生成数据+训练模型的方法

ARXIV_Diffusion Models for Zero-Shot Open-Vocabulary Segmentation

分割一个图像，对每个类别**生成一批图像**，每个图像**提取DINO、SD等特征**，通过**无监督方法CutLER**提取**前景背景特征原型**。同样对输入图像提取特征，与前景背景特征**原型计算相似度**实现分割。先用CLIP初步挑选类别，用ChatGPT排除背景类别干扰？

ICCV2023_Open-vocabulary Object Segmentation with Diffusion Models
这里的所谓OPEN，指能对SD能生成的任意类别目标，同时能生成MASK，不限制语义类别。先通过SD**生成部分类别图片**，然后用**MASK RCNN推理得到MASK**？通过一个Transformer decoder（不是SD的交叉注意力特征） **建立文本特征和SD特征之间的关系+MLP训练网络**，然后能在其他Unseen类别上生成MASK？

通过文本提示只生成1-2个目标。首先实验训练grounding模块用于生成SD生成图的MASK，然后实验训练语义分割网络，用MaskFormer做backbone，评测open segmentation性能。

代码   https://lipurple.github.io/Grounded_Diffusion/

CVPR2023_Open-Vocabulary Panoptic Segmentation with Text-to-Image Diffusion Models

输入图片，**生成隐含的Caption**，然后作为条件输入给Stable Diffusion，进而**提取UNet语义特征**（需要在有标注的基类数据集上训练。通过计算每个Region图像特征和CLIP文本**特征相似性**，可以泛化到Novel类）。

代码 https://github.com/NVlabs/ODISE

ICCV2023_DiffuMask_ Synthesizing Images with Pixel-level Annotations for Semantic Segmentation Using Diffusion Models
* 通过**SD的交叉注意力**得到注意力图，然后**通过AffinityNet网络学习自适应的二值化**，**交叉验证去掉噪声，CRF**，用VOC上训练过的**MaskFormer**推理作为伪真值**评测**性能。Open vocabulary zero shot达到**SOTA**
* 提示语言用WIKI上多个子类，从真实语言中检索最相关的。采用拼图、模糊、遮挡、仿射变换等数据增强方法。只生成一个目标？

代码 https://weijiawu.github.io/DiffusionMask/

NIPS2023_Dataset diffusion_ Diffusion-based synthetic dataset generation for pixel-level semantic segmentation

通过ChatGPT、COCO数据集的Caption，VOC数据集生成Caption，得到提示语言，并加上类别单词确保每个类别都生成了（看来提示语言非常重要？分析在Table2）。通过**SD的自注意力和交叉注意力得到初步分割**，标记为前景、背景、未知，训练语义分割网络。

生成的syncVOC上**性能超过DiffuMask**（只能生成单个目标？），生成的syncCOCO上性能达到真实图像全监督方法
