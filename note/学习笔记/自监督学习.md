定义:自监督学习主要是利用辅助任务( pretext )从大规模的无监督数据中人为构造监督信息，学习到对下游任务有价值的表征与监督学习相比，自监督学习的监督信息是人为构造的。

根据人为设计的不同pretext（辅助任务）方法，自监督学习可以分为以下三种:
1.基于上下文( context) : BERT、RelativePosition、Jigsaw、Colorization、Rotation、Inpaint
2.基于时序( temporal) : TCN、Siamese-triplet Network、Monodepth2
3.基于对比 ( contrastive) : InstDisc、LocalAgg、CPC vl、CPCv2、CMC、MoCo、SimCLR、 MoCo v2

## 1.1 基于上下文(Context based)
完形填空，将完整的图片分为patchs
* 预测patchs之间的相对位置来产生损失
* 随机删除一部分patch，用剩余的patch预测还原
* 输入灰度图，预测原本的色彩

* 《Rethinking Data Augmentation: Self-Supervision and Self-Distillation》
* 分类任务学习类别，自监督学习相同图像增强后的不变性
* Data Augmentation会将原图进行一些变换，扩充数据集并提高泛化能力
	* 作者提出图像在增强后仍强制特征保持不变性，会使学习更加困难。在损失计算时将分类任务的类别和自监督学习的类别组合成更多类别，在输入自监督网络时标注做了什么修改更有利于学习，例如(cat,90)表示是猫的图片，旋转了90度
* **Self-distillation from aggregation**
	* 在学习时限制不同旋转角度的平均特征表示和原始图片的特征表示尽可能接近

## 1.2 基于时序(Temporal based)
* 《Time-Contrastive Networks: Self-Supervised Learning from Video》
	* 视频相邻帧的特征相似；
	* 多视角拍摄的同一帧特征应相似；
* 《Unsupervised Learning of Visual Representations Using Videos》
	* 无监督追踪
	* 一个物体追踪框在不同帧的特征应该是相似的
	* 不同物体追踪框的特征应该是相似的
* 《Shuffle and learn: unsupervised learning using temporal order verification》
	* 打乱帧的顺序，构成正负样本对训练
	* 也是对比学习思想

## 1.3 基于对比(Cotrastive based)
构建正负样本对，**度量正负样本距离**来自监督学习
* Deep InfoMax《Learning deep representations by mutual information estimation and maximization》 
	* 全局特征与局部特征
	* 正样本对：相同图像的全局特征与局部特征
	* 负样本对：不同图像的全局特征与局部特征
	* 背景的局部特征与全局特征不应相似？
* CPC，《Representation Learning with Contrastive Predictive Coding》
	* 主要思想是基于过去的信息预测未来数据
	* 可以将图像视为像素或图像块组成的序列,希望学习随时间不会快速变化的特征
	* 自回归思想，对相隔多个时间步长的数据之间共享的信息进行编码学习
	* 正样本是这段序列t时刻后的输入
	* 负样本是**其他序列**中随机采样的数据
* Moco《Momentum Contrast for Unsupervised Visual Representation Learning》
	* 使用队列存储对应关系的对比数据，提高负样本的数目
	* 提出**动量更新**方法平滑更新参数

	* a 传统方法是q和k均使用编码器提取

* SimCLR《A Simple Framework for Contrastive Learning of Visual Representations》
	* 增强后的图片分别提取特征，用全连接层最大化同一张图片增强出来的图片特征的相似度





### CPC
* 对于样本j的CPC特征提取过程
	* $x_j(t)=[x_j(1),x_j(2),\cdots,x_j(n)]$表示个体j的时间序列
	* $z_j=z_j(1),z_j(2),\cdots,z_j(m)$表示其内含的特征
		* 随机选择一个时间点m，将m之前所有提取到的特征$z_j(1),z_j(2),\cdots,z_j(m)$用一个回归模型来总结信息（例如用RNN），然后用线性变换来预测$\hat{z}_j(m+1),\hat{z}_j(m+2),\cdots,\hat{z}_j(m+K)$
		* 实际上发生的事情是$x_j(m+1),\cdots,x_j(m+K)$,其应该对应的特征是$z_j(m+1),\cdots,z_j(m+K)$
	* 理想情况下$\hat{z}_j(i)$与$z_j(i)$应该是相似的
	* 而对于另一个样本l的特征$z_l(i)$就应该与预测得到的$\hat{z}_j(i)$不相似
	* 则正样本为$\hat{z}_j(m+i)$与$z_j(m+i)$；
	*    负样本为$\hat{z}_j(m+i)$与$z_l(m+i)$；
	* 损失计算的目的就是最大化正样本之间的相似度，最小化负样本间的相似度
