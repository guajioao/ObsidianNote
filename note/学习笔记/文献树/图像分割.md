# [[开放词汇]]
利用跨模态模型（CLIP等）分割出任意文本对应的掩码
* 复杂场景下的mask识别
	* **加强模型形状边缘意识**-SAZS
* 文本与图像特征的对应
	* 直接匹配
		* 作为伪标签不断优化-MaskCLIP、CESL
		* 引入prompt指导加强文本与视觉特征的关联性-DenseCLIP、ZegCLIP
		* 先分出掩码，再分类-Openseg、SimSeg、ZegFormer、SAN
		* 提高masked区域分类准确度-OvSeg
	* 聚类
		* 创建文本-图像特征字典，通过与字典中存储的聚类中心比对获得掩码分类
		* 对比学习+聚类+CLIP，对齐属于同一区域的特征、文本特征和语义特征-CLIP:S4
* seen与unseen类
	* 加强文本图像特征之间的关联
		* prompt
		* 对齐特征空间
