# 第一阶段：百花齐放 18年中-19年中
## [[InstDisc]]
2018.5.5
* 结构图![[Pasted image 20231220153849.png]]
	* 图像用backbone提取出来的特征图都通过线性层转换为128向量存储在Memory bank中
	* 通过对比学习的训练，让这些向量在特征空间之中尽可能的不接近
	* 将每一张图片都视为一个独立的个体，学习一个特征能够区分每一张图片
	* 128维是因为要存储所有图片，因此限制了维度
* 提出了Instance distance 这个代理任务
* 使用NCE计算Instance distance来做对比学习
* 提出可以用其他数据结构存储大量的负样本，以及如何对这些特征进行动量更新
* 提出Proximal Regulariation，给模型训练增加一个约束，让其损失下降更加平滑【与MoCo使用的动量相似】

## InvaSpread
2019.8.6
* 正负样本来自同一个mini-batch，不用其他数据结构存储负样本
	* 正样本还是原始图片x1增强后的图片x1'
	* 负样本是所有除x1和x1'外所有图片，包括为未增强的图片
	* 即：正样本数是256，负样本数是$(256-1)\times 2$
	* 这样就可以用一个编码器进行端到端的训练
## CPC
2018.7.10
* CPC，《Representation Learning with Contrastive Predictive Coding》
	* 主要思想是基于过去的信息预测未来数据
	* 可以将图像视为像素或图像块组成的序列,希望学习随时间不会快速变化的特征
	* 自回归思想，对相隔多个时间步长的数据之间共享的信息进行编码学习
	* 正样本是这段序列t时刻后的输入
	* 负样本是**其他序列**中随机采样的数据
## CMC
2019.6.13
* 一个物体的多个视角都可以被视为正样本
* 因此对一个物体的任何形式的描述提取到的特征都应该是相似的【CLIP同理】
* 任何模型对于同一个物体提取出的特征也都应该是相似的，即teacher模型的输出与studet模型的输出尽可能的相似，则teacher和student就可以作为一个正样本对，做对比学习
* 局限性：不同端需要配不同的编码器。
	* 但是由于Transformer的特性，可以处理多个任务
	* ma clip：一个Transforemr同时处理两个输入模态
* 作者的另一个蒸馏相关论文：CONTRASTIVE REPRESENTATION DISTILLATION

### [[MOCO]]
上传arxiv时间2019.11.13
* 将之前的对比学习方法都总结为一个字典查询问题
* 提出队列和动量编码器，从而更大更好的进行对比学习
* 可以视为InstDisc的改进工作
* 工作简单有效
* 引言写的很好，直接归纳升华整个对比学习问题


### [[SimCLR]]
IMLS2020
![[Pasted image 20231220205831.png|375]]
* 同样是用x提取出的特征和x增强后的图片提取出的特征做正样本
* 新增的是在提取特征之后加了projector做降维，即跟着一个简单的MLP全连接层+（ReLu激活函数）【就是$g(\cdot)$】做线性变换，简单有效，直接提高10%精度
* g函数只在训练时使用，做下游任务时扔了
* 整个过程非常简单，就是图像进入编码器编码，然后projector降维，最后计算对比学习的loss
* 使用lars优化器来做大batchsize的训练【之后的工作也沿用了这个设计】

### MOCO V2
原有的MOCO V1基础上
* 结合了SimCLER的MLP层设计
* 使用更多的数据增强
* 训练更多轮次（800）
* 相比SimCLR硬件要求更低，训练时间更短
（3月9号发，里SimCLER的2月13号相差不到1个月）

### SimCLR V2
* Big Self-Supervised Models are Strong Semi-Supervised Learners
* 对simclr的改进只是一小部分，大部分在说如何做半监督学习
* 受19年noisy student的思路：
	* 先在ImageNet上训练一个teacher模型，然后在更大的JFT300M上生成很多个伪标签，训练一个student模型。这个student模型在Imagenet原数据集上性能更好
* v2改进：
	* 换了一个更大的模型
	* projection head增加层数（2层）
	* 用了MOCO的动量编码器

### SwAv
2020.6.17
* 同一张图片的多个视角得到的特征应该是接近的
	* 一个视角得到的特征可以用于预测另一个视角得到的特征
* 基于聚类算法DeepCluster/DeepCluster2
* 对比聚类方法![[Pasted image 20231222153551.png]]
	* 总结之前的对比学习方法，都是用编码器提取特征后做对比
	* 这样做有些浪费资源，修改为不用特征互相比，而是用特征与聚类中心 $c$ 比。
	* $c$ 是一个矩阵，维度是$D\times K$ ，D是特征维度，K是聚类中心个数
	* 特征z与矩阵c相乘生成一个目标Q。如果z1和z2是正样本，那么他们与C相乘得到的Q1，Q2就应该相似。这种代理任务称为换位预测"swapped prediction"
* Multi-Crop方法
	* 在图片里多crop一些区域，就能关注更多的区域
	* 为了计算量不增加太多，将原本取2个224的区域变为取$2\times160+4\times96$ 的区域
	* 对结果的提升+4.0

# 第三阶段：不用负样本

### BYOL
Bootstrap your own latent
* 在自己的特征基础上改进
* ![[Pasted image 20231222164912.png]]
	* 与之前的工作一样，有query编码器和key编码器，分别提取特征后经过一个MLP得到$z_{theta}$和$z_{\xi}$。key编码器也是一个动量编码器
	* 用$q_{\theta}$这个MLP来预测一个$q_{\theta}(z_{\theta})$，希望与$z_{\xi}$尽可能接近
	* 相当于用一个视角的特征去预测另一个视角特征，用预测型的任务

### SimSiam
之前嗯对工作提出了很多trick作者希望能够化繁为简，证明即使不用那些技巧对比学习也能训练得很好
将整个步骤简化为
1. 数据增强为x1,x2
2. 提取特征的z1,z2
3. 预测头推理得p1,p2
4. 计算损失：用p1预测z2,用p2预测z1
因为有stop gradient这个操作，所以模型不会坍塌，其实相当于模型的一套参数被分成了两份。
最后就能理解为一个k-means聚类问题
* 与其他之前工作的对比
	* ![[Pasted image 20231224150226.png]]
* SimCLR两端都有梯度回传，都是做对比任务
* SwAV也是对比任务，但是不跟负样本比，而是跟聚类中心比
	* 聚类中心通过Sinkhorn-Knopp算法得到
* BYOL提出predictor，将对比任务转换为预测任务
	* 使用动量编码器
* SimSam左边跟BYOL一样，右边没有使用动量编码器，而是使用参数共享的encoder
* 实验结果
	* ![[Pasted image 20231224152619.png]]
	* 训练更快，消耗资源更少，迁移到下游任务后的能力更好

# 第四阶段：Transforemr
### MOCO V3
* ViT用在无监督学习
* 大篇幅在讲如何提高ViT训练的稳定性
* MOCO V3相当于MOCO V2和SimSiam的结合：
	* query编码器和key编码器，key编码器是动量编码器
	* 目标函数是对比学习
	* query编码器是backbone+projection mlp+prediction mlp【BYOL或SimSiam的设计】
	* 损失函数即算q1到k2的，又算q2到k1
* 将backbone替换为ViT后发现训练batchsize增大后会出现训练一段准确度突然下降的情况，且当batchsize=6144时准确度掉的很快，最终效果不好。即训练不稳定
	* 作者提出一个trick来解决这个问题
	* 观察梯度回传发现当准确度波动时第一层linear projection的梯度也会出现波动
	* 于是在随机初始化第一层参数后就直接冻住，在后续训练过程中不再改变。于是训练稳定了，结果也更好。甚至在BYOL中也有用

### DINO
Self-distillation with no labels【自蒸馏】
即使没用标签，将自注意力图拿出来也能对物体的轮廓扣的很精准
* 结构与BYOL很相似：
	* ![[Pasted image 20231224155842.png|475]]
	* 用student来预测teacher，因此teacher网络的输出就可以想成是GT
	* 为避免模型坍塌，在teacher后面加了一个centering，即将整个batch的样本计算均值，然后减去这个均值
	* teacher网络是stop gradient的【sg】
