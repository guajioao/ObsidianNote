# 第一阶段：百花齐放 18年中-19年中
## InstDisc
* 结构图![[Pasted image 20231220153849.png]]
	* 图像用backbone提取出来的特征图都通过线性层转换为128向量存储在Memory bank中
	* 通过对比学习的训练，让这些向量在特征空间之中尽可能的不接近
	* 将每一张图片都视为一个独立的个体，学习一个特征能够区分每一张图片
	* 128维是因为要存储所有图片，因此限制了维度
* 提出了Instance distance 这个代理任务
* 使用NCE计算Instance distance来做对比学习
* 提出可以用其他数据结构存储大量的负样本，以及如何对这些特征进行动量更新
* 提出Proximal Regulariation，给模型训练增加一个约束，让其损失下降更加平滑【与MoCo使用的动量相似】

## InvaSpread
* 正负样本来自同一个mini-batch，不用其他数据结构存储负样本
	* 正样本还是原始图片x1增强后的图片x1'
	* 负样本是所有除x1和x1'外所有图片，包括为未增强的图片
	* 即：正样本数是256，负样本数是$(256-1)\times 2$
	* 这样就可以用一个编码器进行端到端的训练



## CPC
* CPC，《Representation Learning with Contrastive Predictive Coding》
	* 主要思想是基于过去的信息预测未来数据
	* 可以将图像视为像素或图像块组成的序列,希望学习随时间不会快速变化的特征
	* 自回归思想，对相隔多个时间步长的数据之间共享的信息进行编码学习
	* 正样本是这段序列t时刻后的输入
	* 负样本是**其他序列**中随机采样的数据



## CMC
* 一个物体的多个视角都可以被视为正样本
* 因此对一个物体的任何形式的描述提取到的特征都应该是相似的【CLIP同理】
* 任何模型对于同一个物体提取出的特征也都应该是相似的，即teacher模型的输出与studet模型的输出尽可能的相似，则teacher和student就可以作为一个正样本对，做对比学习
* 局限性：不同端需要配不同的编码器。
	* 但是由于Transformer的特性，可以处理多个任务
	* ma clip：一个Transforemr同时处理两个输入模态

# 第二阶段：CV双雄 19年中-20年中
### MOCO
* 将之前的对比学习方法都总结为一个字典查询问题
* 提出队列和动量编码器，从而更大更好的进行对比学习
* 可以视为InstDisc的改进工作
* 工作简单有效
* 引言写的很好，直接归纳升华整个对比学习问题


### SimCLR
![[Pasted image 20231220205831.png|375]]
* 同样是用x提取出的特征和x增强后的图片提取出的特征做正样本
* 新增的是在提取特征之后加了projector做降维，即跟着一个简单的MLP全连接层+（ReLu激活函数）【就是$g(\cdot)$】做线性变换，简单有效，直接提高10%精度
* g函数只在训练时使用，做下游任务时扔了
* 整个过程非常简单，就是图像进入编码器编码，然后projector降维，最后计算对比学习的loss
* 使用lars优化器来做大batchsize的训练【之后的工作也沿用了这个设计】
