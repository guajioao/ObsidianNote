# 语义分割
### 掩码生成
* [[MaskCLIP]]:Extract Free Dense Labels from CLIP
	* 监督学习，需要ground truth类别掩码监督训练
	* 直接对特征图进行处理（两层卷积）
	* 对图像编码器最后一层的**特征图直接卷积然后上采样**得到掩膜输出
* [[DenseCLIP]]:Language-Guided Dense Prediction with Context-Aware Prompting
	* 监督学习，需要ground truth类别掩码监督训练
	* **逐像素分类**问题
	* 特征图与文本特征计算相似度，得到**分数图**
	* 文本特征中引入视觉上下文信息prompt
* [[ZegFormer]]: Decoupling Zero-Shot Semantic Segmentation
	* 监督学习，需要GT来计算mask loss
	* 将**Zero-shot semantic segmentation** (ZS3)任务转化为**两个子任务**
		* **生成mask**：用视觉特征图与queries处理后获得**类别无关的mask**和与文本特征对齐的视觉语义分割embeddings-Semantic segment embedding【**生成mask精度提高的同时与文本特征对齐**】
		* **求mask类别**：masked图像与文本特征求相似度**获得mask的类别**【是mask还是crop，作者表示没区别】
* [[OpenSeg]]:Scaling Open-Vocabulary Image Segmentation with Image-Level Labels
	* 监督学习，需要一个类别无关的分割标注
	* **在图像特征图上进行mask**
	* 使用backbone提取特征，并使用一个**交叉注意力模块来产生N个masks**
	* 用这些mask与image特征进行Mask-based pooling，得到N个mask的图像特征
	* 与文本特征进行匹配
* [[SimSeg]]:A Simple Baseline for Open-Vocabulary Semantic Segmentation with Pre-trained Vision-language Model
	* 掩膜生成之后**mask原图**，然后输入图像编码器中提取masked image特征，最后与文本特征进行相似度计算与**分类**
### 类激活图
* [[CLIMS]]:Cross Language Image Matching for Weakly Supervised Semantic Segmentation
	* 使CAM(Class ActivationMap)中目标对象激活更完整,抑制与物体相关的背景区域
	* 通过CLIP，引入自然语言来达成上一目的
	* 弱监督

# Referring Image Segmentation，RIS
* [[CRIS]]: CLIP-Driven Referring Image Segmentation
		* 设计视觉-语言**解码器**，来根据文本特征增多**像素级视觉特征**的细粒度语义信息
	* 将像素级视觉特征V与全局语义信息T通过对比学习，来pull文本与相关的像素特征closer，push其他无关的away
